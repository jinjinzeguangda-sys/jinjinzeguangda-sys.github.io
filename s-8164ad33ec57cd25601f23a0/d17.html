値段（Item Price）の決め方

  • 基本は、eBay注文の My note に書いてある商品代（送料は無視）です。
    例: note が「駿河屋 1,500円＋送料780円」なら、Item Price は 1,500円（送料の780円は入れません）。
  • Prepay アプリの写真から出た価格が、note の商品代より安いときだけ、そちらを使います（同額・高いときは note）。
  • 優先順位（道具の中）: 注文ごとの個別指定 ＞ note ＞ 台帳の仕入れ値 ＞ 売値の換算。
  • note から値段が読めないとき（Amazon価格だけ・買った店が2つ以上・店名が辞書に無い・個数2以上）は、数字を作らず空欄にして理由を付けます。点検（audit）が ★NG にして、Zonosに上げさせません。
  • 10/31は「Amazonで仕入れた時の値段」と指示があり、同日に「note の値段（送料は無視）」へ広がりました。後者が現在の形です。

  • 発送は1週間に数十個で、手動でも1商品1分ほどで終わる。一方、開発には何日もかかるため、効果が見合わない。
  • 1日100商品ほど売れるようになれば効果が見込める。まずはCSVより受注を増やす。

技術メモ・注意（クリックで開く）
  • CSVを Calc で保存しない。9503.00 が 9503 に変わります。Zonosには元のファイルをそのまま上げます。
  • 買い手の氏名・住所が入ったCSVは、父の共有フォルダに置きません。
  • 「準備完了／0エラー」は書式の検査だけです。関税の番号や値段が合っているかは見ていません。
  • note の読み方: ✔店名 価格＋送料 の✔は買った店、× は買えなかった店、A to B は値段が変わった（現在値は B）。✔があればその店の商品代。✔が無ければ、×を除いた店の商品代の最安。Amazon価格・JAN・題名の数字は拾いません。店名の辞書は6店（駿河屋・YS Joshin・バリQ・桃太郎王国・あみあみ・BM）で、新しい店が出たら足します。
  • note の取り方: 父/本人がログイン済みのChromeで、eBayの注文詳細から読みます。eBay APIでは取れませんでした。
  • HSの判定は、記録物（CD・映像・ゲーム）を出品側と日本郵便側で食い違わせないことが肝心です。食い違うと、関税12.5%を払うか、キットを8523.49（関税0）で申告する誤りになります。
